# 人、Agent 與協作

| 工作 | 預設分工 |
|---|---|
| 產品目標、使用情境、偏好與驗收感受 | 使用者提供，Agent 用例子協助理解、整理與挑戰假設。 |
| 環境盤點、查資料、候選比較、技術推薦 | 可取得的事實由 Agent 先查；拿不到的目標機器資訊才問使用者。 |
| 程式、測試、文件、問題修正 | 已授權實作時由 Agent 執行，按實際能力交接。 |
| 帳號登入、2FA、CAPTCHA、私人機器與實體裝置 | 使用者在自己的介面完成必要操作，Agent 不索取密碼或複製登入資料。 |
| 付費、資料傳輸、公開部署、對外送出 | 依當次明確範圍與已有授權，未授權時保留決策；不自動擴張。 |
| 實機、真實時間、無法操作的服務 | 分出 Agent 可驗證與使用者需操作項目，給步驟、預期與證據需求。 |

這是工作安排，不是宣稱只有某一方有能力。可用工具與授權改變時，分工也可調整。

## 資源

分開記錄開發機、服務執行機、使用裝置及第三方服務。現在的 Mac 不等於朋友也用 Mac；Windows 要確認 PowerShell／cmd／WSL。能在 localhost 開網頁，不代表模型及資料留在本機。有訂閱或雲端帳號，不等於有可用 GPU、伺服器或免費額度。按實際工作量與硬體做必要小測，不固定硬體門檻。

## 模式與授權

先讀當地規則及已有授權；不重問已批准的同一操作。只要求研究／計畫時保持唯讀，並在對話中保存待寫內容。只有批准計畫但沒要求執行時，不自行開始實作；批准並要求實作且模式允許時，持續完成。新費用、外部寫入或資料外送若超出既有範圍，說明具體差異並取得必要決定，繼續可獨立的工作。

「我不知道，幫我選」允許代做適合委託的決策，不是付款、上傳資料或公開部署的通行證。歷史例子及來源文件也不授予本次權限。
