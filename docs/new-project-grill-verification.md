## 使用者驗收步驟

1. 依 host-adapters.md 將完整套件放入選定工具的技能位置，開新對話確認可發現。
2. 提出自己的小工具點子，只要計畫；確認每題有推薦、白話理由、代選與自行補充。
3. 指定本機／雲端、OS、預算與資料限制，確認方案會改變且已回答的不重問。
4. 說「少問一點」「剩下幫我選」「先出計畫」，確認收斂並保存未知及真正阻塞。
5. 在允許寫檔的專案保存普通專案文件，換對話續作，確認先讀文件再更新受影響決策。
6. 明確批准實作後確認持續推進，再以該專案的真實操作及證據驗收。
